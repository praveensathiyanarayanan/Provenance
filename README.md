# PROVENANCE — Luxury Architectural Sanctuaries & Private Residences

An ultra-luxury, editorial real estate digital experience inspired by contemporary brutalist and minimalist architectural design.

## Features

- **Fixed Top Navigation**:
  - Pinned frosted-glass header with imperial Cinzel `PROVENANCE` branding and gold-honed navigation pills.
  - Live shortlist counter and one-click quick jump links across sections.
- **Cinematic Living Motion & Interactive Canvas**:
  - Seamless 60 FPS continuous ambient living motion stage.
  - Interactive multi-perspective spatial inspection and dynamic ambiance modes.
- **Universal Click-to-Zoom Lightbox**:
  - Click any architectural photograph or gallery image across the website to trigger high-resolution modal zoom with touch/drag dismiss and backdrop blur.
- **Curated Architectural Finishes & Material Lab**:
  - Interactive tactile material selector (Honed Carrara Calacatta, Shou Sugi Ban Cypress, Triple Low-E Acoustic Glass, Brushed Champagne Titanium).
  - Micro-loupe inspections, STC acoustic ratings, thermal ratings, and bespoke material swatch ordering.
- **Bespoke Builder & Artisan Strip Marquee**:
  - Continuous marquee ticker showcasing premier builders, master craftsmen, and engineering consortia across Milan, London, New York, Singapore, Monaco, Zurich, and Dubai.
- **Client Recognition Infinite Marquee**:
  - Leftward continuous carousel featuring architectural critics, design principals, and private equity visionaries.
- **Concierge Private Acquisition Advisory Form**:
  - Structured acquisition enquiry form for private dossier delivery and off-market viewing arrangements.
- **Dynamic Property Detail Modal & Saved Shortlist**:
  - High-resolution multi-angle gallery with thumbnail switcher.
  - Interactive mortgage calculator and architectural specifications.
  - LocalStorage-backed shortlist favorites drawer.

## How to Run

1. Open `index.html` directly in any modern browser:
   ```
   index.html
   ```
2. Or run locally with Node.js:
   ```bash
   node server.js
   ```
   and navigate to `http://localhost:2001`.
